# CUSTOMER-ANALYSIS
Customer Analysis project exploring customer behavior, purchasing patterns, sales performance, and customer segmentation through data analysis and visualization.
# Customer Analysis Excel Dashboard

## Project Overview

This project presents an interactive Customer Analysis Dashboard created in Microsoft Excel. The dashboard provides insights into customer sales performance, regional sales, monthly sales trends, product category contribution, customer-wise analysis, and regional profitability.

The purpose of this project is to understand customer purchasing patterns and identify important sales and profit trends through interactive Excel visualizations.

## Dashboard Features

- Sales performance by region
- Monthly sales trend analysis
- Product category-wise sales contribution
- Customer-wise sales analysis
- Profit comparison across regions
- Customer ID slicer for interactive filtering
- Product category filter
- Region filter
- Order date timeline
- Interactive PivotCharts and PivotTables

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Timeline Filter
- Data Analysis
- Data Visualization

## Key Insights

- The dashboard compares sales performance across Central, East, North, South, and West regions.
- Monthly sales trends help identify changes in customer purchasing activity.
- Product categories such as Books, Clothing, Electronics, Furniture, and Office Supplies are compared.
- Customer-wise analysis helps identify customers with higher sales contributions.
- Regional profit analysis shows differences in profitability across locations.
- Interactive filters allow users to explore specific customers, categories, regions, and order periods.
